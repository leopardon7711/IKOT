IKOT v6 AIセットアップ

1) Supabase > SQL Editor
   supabase_setup.sql を実行

2) Supabase > Edge Functions
   関数名: ikot-ai
   index.ts の内容を配置して Deploy

3) Edge Function > Secrets
   OPENAI_API_KEY = OpenAI API key
   OPENAI_MODEL = gpt-5.6-luna  （任意。なくても動く）

4) IKOTを開いてInstagram等から共有
   URL入力後にAIが自動で情報を整理する

※ OpenAI APIキーを index.html やGitHubに書かないこと。
